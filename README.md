# Siri Anubolu — Professional Portfolio (AIML-500)

Static portfolio site with two artifacts:

- `timeline.html` — Artifact 01: From Turing to Transformers (interactive AI history)
- `glowcare.html` — Artifact 02: GlowCare Complaint Care Assistant (prompt-engineered chatbot demo)
- `Siri_Anubolu_Resume.pdf` — downloadable resume

## Deploy to Vercel
1. Push this folder to a GitHub repo (e.g. `portfolio`)
2. vercel.com → Add New → Project → Import the repo
3. Framework preset: **Other** · no build command · output directory: `./`
4. Deploy → your site is live at `https://<project>.vercel.app`

No build step, no dependencies — pure static HTML/CSS/JS.
